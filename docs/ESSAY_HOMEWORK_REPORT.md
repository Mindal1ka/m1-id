## 1. Підсумок
- Есе — це **не окремий ендпоінт і не окреме поле типу**. Це ДЗ зі `is_autotest === 2` ✅.
  Для звичайного ДЗ `is_autotest` порожнє/0, для автотесту — інше ненульове значення (точне ⚠️).
- Форма здачі есе — **лише текст**: зона завантаження файлів не показується, лишається одне велике текстове поле ✅.
  Ваше спостереження правильне.
- Відправка йде тим самим запитом `POST /{alias}/homework/create`, що й для файлів; для есе просто `filename`/`clientFilename` = `null` ✅.
- Для есе **немає «запиту на перездачу»** ✅.

## 2. Як визначається тип
| Ознака | Значення |
|---|---|
| `ospr` | `0` = самостійна (`independent_work`), `1` = практична (`practice_work`) |
| `is_autotest` | `2` → **`essay`**; інше ненульове → автотест ⚠️ |
| Підпис типу | `getTypeLabel(ospr, is_autotest)`: якщо `is_autotest === 2` → `essay`, інакше за `ospr` ✅ |

Фільтр списку: `type[]` у `GET /{alias}/homework/list` — `1` homeworkAndTests, `2` practicalWord, **`3` essay**, `-1` тести ✅.
Тобто есе окремо відбирається параметром `type[]=3`.

## 3. Що змінюється в UI для есе
| Місце | Звичайне ДЗ | Есе |
|---|---|---|
| Підпис типу в списку й картці | «Самостійна»/«Практична» | **«Essay»** |
| Назва/тема (`theme`) | рендериться як HTML (`innerHTML`) | рендериться як текст через переклад (`translate`) ⚠️ (за порядком шаблонів) |
| Форма здачі | зона файлів (drag-and-drop, до 25 МБ) + текстове поле | **тільки текстове поле** (мінімум 3 рядки, автовисота, плейсхолдер `enter_text`) |
| Кнопка «Запит на перездачу» (`retransmission_request`, −2 монети) | є для статусу «Виконано» | **немає** |
| Повідомлення про академвідпустку для виконаного ДЗ | показується | не показується |

Решта поведінки спільна: статуси, дедлайн, оцінка, коментар викладача, видалення розв'язку у статусі «На перевірці».

## 4. Логіка здачі (`sendHomework`) ✅
1. Блокування: у академвідпустці (`is_academic_holiday = 1`) — помилка `cannot_submit_homework_academic_leave`.
2. Кнопка «Надіслати» неактивна, якщо **текст порожній (після `trim`) і немає файлів**, або вже йде відправка. Інакше — помилка `enter_text_upload_file`.
3. Якщо є файли: усі пакуються в один zip `«{ПІБ}-{група}.zip»` → завантаження у файловий сервіс (каталог `homeworkDirId`) → беруться `link` і `client_name`.
4. `POST /{alias}/homework/create`, JSON:
   ```jsonc
   { "answerText": "текст або null",
     "filename": "<link zip>|null",
     "clientFilename": "<ім'я zip>|null",
     "id": <id завдання> }
   ```
   Для есе файлів нема, тому `filename = clientFilename = null`, відповідь студента лежить у `answerText`.
5. Після успіху: оновлення списку й лічильників, тост `success`, закриття панелі.

Коли можна здавати: статус `3` (до виконання), `5` (перездача), `6` (прострочено) і не академвідпустка; або відкрита перездача ✅.

## 5. Ціна в монетах ✅
- Кнопка «Надіслати» показує **`−20`**, якщо дедлайн минув більше ніж 182 днів тому, це не перездача і `homework_stud.unlock_expire !== "1"`.
- Під час перездачі показується **`−2`**, поряд є кнопка «Скасувати».
- Умова блокування в коді містить перевірку `coins < 20`, але вона перекривається першою умовою (порожня відповідь) і окремо нічого не додає ⚠️.
Ці правила однакові для есе й звичайного ДЗ; різниця лише в тому, що перездачі для есе нема.
