# FRONTEND_REWRITE — аудит і план переписування фронтенду M1 ID

> Складено: 2026-10-17 за результатами аудиту `m1-id/frontend` (4 паралельні огляди: шелл/дизайн-система,
> основні екрани, другорядні екрани, лендінг/вхід). Мета — фронтенд, який **зручніший, красивіший, сучасніший**.

---

## 1. Поточний стан — коротко

**Розмір:** 104 файли, ~36k рядків; 65 `.svelte` ≈ 27.8k рядків, з них **~48% — `<style>`**.
Стек: SvelteKit 2 + Svelte 5 (runes), Vite 8, TS 6, adapter-static, lucide. Без UI-бібліотеки, без тестів.

### Головні проблеми

| Область | Проблема |
|---|---|
| Архітектура | `routes/app/+page.svelte` (1732 р.) — god-component: ~70 `$state`, boot/refresh/WS/polling, увесь `{#if tab===…}`. Навігація — не роутинг SvelteKit, а `tab` + ручний `history.pushState`. Локальні копії даних поруч зі store + `uiTick` для ручної синхронізації. |
| Компоненти | `HomeView` 2059 р. (330 р. — математика drag/resize), `NutritionTab` 1233, `VaultPane` 1358, `NotesPane` 1022. Prop drilling по ~20 пропсів. |
| Дизайн-система | Токени лише для кольорів/радіусів; **немає** шкали відступів, типографіки, z-index, тривалостей. 300 р. `nth-child` у `tokens.css`. **160 hex + 158 rgba** захардкоджено, 11 різних брейкпойнтів (nav — 900, device — 600/1180, swipe — 860). |
| Примітиви | Немає Button/Input/Tabs/Switch/Card. `AppModal` є, але його використовують 4 файли; **8+ модалок** з власним overlay, **7 копій `portal()`**, focus trap лише у 3 місцях. 5 нативних `confirm()`; 3 різні реалізації toast. Кнопки: `btn`, `btn f`, `act`, `cta`, `ib`, `mini`, `ghost-btn`… |
| Візуал | «Aurora Glass»: `backdrop-filter` на кожній картці + 3 анімовані блоби blur 90px — важко для слабких телефонів. Світла тема лише на рівні змінних (багато темних хардкодів). Емодзі як іконки (🎉 🛋 ⠿ ✕ ✅ 🤖). Дрібні шрифти 11.5–12px. Картка-в-картці для кожної вкладки. |
| IA / навігація | На мобільному 4 вкладки внизу, ще 10+ — за «Інше». «Нотатки» = 3 різні продукти (нотатки, паролі, файли) в одній вкладці. «Додаткові» — 2 перемикачі. Налаштування, профіль, M1-посилання — у модалках, хоча це сторінки. |
| UX основних екранів | Головна: 7 рівноцінних карток, немає «наступна пара / що здати сьогодні». Розклад: місяць — список, тиждень вирівняний за індексом пари, а не за часом; немає «зараз». ДЗ: немає групування за терміновістю, пошуку, фільтра «прострочені». Оцінки: колір чипа = тип роботи, а в розкладі/ДЗ колір = якість оцінки (дві системи). Здача: технічний вибір «Itstep vs M1 Provider» до вибору файлу. Переглядач файлів щоразу питає «відкрити в браузері?». |
| Вхід / онбординг | CTA «Перейти →» веде анонімного на /app → мовчазний редірект на /login. ~5 екранів і 3 форми до першого контенту. Немає відновлення пароля (`/reset` — це очищення кешу). Дві різні пари логін/пароль (M1 ID і MyStat) ніде не пояснені. Інтро лендінгу ~6 с, `motion.ts` 1132 р. + 632 р. CSS. Усі CTA — `data-sveltekit-reload` (повне перезавантаження). |
| Доступність | Немає `aria-current` у навігації, меню без клавіатури/Esc, клікабельні `div` без ролей, hover-only поповери. |
| Мова | Знайдено російське: коментар `HomeworkView.svelte:50`, «не хватає» у `ShopTab`. Тон «ти/ви» змішаний. |

## Рішення власника (2026-10-17)

- **Візуал:** «чистий сучасний» — спокійні поверхні, тонкі рамки, велика типографіка, повітря; скло лише в навігації, Aurora — опційно; темна і світла теми рівноправні.
- **Підхід:** поетапно на місці, у тій самій теці `frontend`; після кожного етапу — робоча збірка.
- **Навігація:** лишити близькою до поточної (ті самі вкладки), але акуратніше оформленою. Нова 5-розділова IA з розд. 4 — **не приймається**; з неї беремо лише точкові речі (сторінки налаштувань замість модалок, деталі як sheet на мобільному).

## 2. Що зберігаємо без змін (UI-незалежний шар)

- `lib/api/client.ts` (~140 методів, ~90 типів; refresh через `navigator.locks`, таймаути, ретраї) і `lib/api/sync_ws.ts`.
- Логіка store: `auth` (localStorage + cross-tab), правила кешу `appStore` (SWR, FRESH 5 хв, de-dupe, per-account, purge при виході).
- PWA: `static/sw.js`, трійка `__BUILD_STAMP__` / `version.json` / SW VERSION, `UpdateGate`-логіка, `cachePurge` (префікси `m1id.cache.`, `fs_menu_`), manifest, CSS prefix guard, правило «дві HTML» (пререндер `/` + `app.html` як SPA fallback).
- SEO лендінгу (`seo.ts`, JSON-LD, robots/sitemap, noindex).
- Протокол QR-входу, перевірка `next`, deep links (`?hw=`, `?lb=`, `?account=`, `?plg=`) з перевіркою власника logbook.
- Усі функції екранів (повний перелік — у розд. 6).
- Деталі: `touch-action: manipulation`, 16px у input на iOS, `100dvh` + safe-area, `viewport-fit=cover`, захист від тапів під час скролу.

## 3. Цільова архітектура

1. **Справжній роутинг SvelteKit** з layout-шеллом:
   `/app/(shell)/+layout.svelte` (сайдбар/нижня панель, топбар, sync-статус) і сторінки
   `home`, `schedule`, `study/{homework,marks,activity}`, `campus/{shop,nutrition,payments,contacts,news,leaderboard}`,
   `space/{notes,vault,files}`, `settings/{profile,appearance,notifications,links,plugins,developer}`.
   `ssr=false` залишається; пререндериться лише лендінг. Deep link `?hw=` → `/app/study/homework/[id]` (старі параметри редіректимо).
2. **Дані — тільки через store** (без локальних копій і `uiTick`); кожна сторінка сама викликає `store.ensureX()`. Boot/refresh/WS/watchdog — в одному модулі `lib/app/session.svelte.ts`.
3. **Бібліотека компонентів `lib/ui/`** — один раз, використовується скрізь:
   `Button`, `IconButton`, `Card`, `PageHeader`, `Tabs/Segmented`, `Switch`, `SettingRow`, `Field`, `Input`, `Select`, `Textarea`, `SearchField`,
   `Dialog` (desktop) ⇄ `Sheet` (mobile) з focus trap/Esc/portal, `ConfirmDialog` + `confirm()`-promise, `Popover/Tooltip`, `Toast`,
   `ListRow`, `ListDetail`, `EmptyState`, `ErrorState` (з retry), `Skeleton`, `Badge/StatusChip`, `GradeBadge`, `CopyButton`, `Stepper`, `FileDrop`, `InfiniteList`.
   Для доступності — headless-примітиви (рекомендовано **Bits UI** для Svelte 5) замість ручних focus trap і portal.
4. **Дизайн-токени**: семантичні кольори (`--color-bg/surface/elevated/border/text/muted/accent/success/warning/danger`), шкали
   відступів (4px-база), типографіки (12/14/16/18/22/28/36), радіусів, тіней, z-index, тривалостей/easing. 3 брейкпойнти: `sm 640`, `md 900`, `lg 1200`.
   Теми = перевизначення семантичних токенів (темна/світла/OLED + 12 акцентів), без JS-інлайн-стилів на кожен токен; без спалаху теми при старті.
5. **Візуал**: «спокійні поверхні» замість скла на кожній картці — суцільні шари з тонкою рамкою, скло лише для навігації/шитів.
   Aurora — опційний ефект (вимикається автоматично на слабких пристроях і при reduced-motion). Тільки lucide, без емодзі в UI.
   Мінімальний шрифт 13px, чітка ієрархія заголовків.

## 4. Нова інформаційна архітектура

**Основна навігація (5):** Головна · Розклад · Навчання · Кампус · Простір. Акаунт/налаштування — аватар у топбарі (desktop) / вкладка «Профіль» (mobile).

| Розділ | Що всередині |
|---|---|
| Головна | Hero «зараз/наступна пара» з відліком, смуга «здати сьогодні/прострочено», далі віджети (налаштовувані). |
| Розклад | Тиждень (вирівняний за часом, лінія «зараз»), місяць — календарна сітка з точками, свайп; деталі пари — sheet. |
| Навчання | ДЗ (групи: прострочено / сьогодні / цей тиждень / пізніше; пошук; швидке «Здати»), Оцінки (одна колірна система за якістю, вигляд «за предметами» з трендом), Нарахування, Прогрес. |
| Кампус | Магазин, Харчування (потік: меню → кошик-sheet → дати → підтвердити; автозамовлення окремою сторінкою), Оплата, Контакти, Новини, Рейтинг/Нагороди. |
| Простір | Нотатки, Паролі (з блокуванням), Файли — три окремі сторінки, master/detail на desktop, push-навігація на mobile. |
| Налаштування | Профіль і сесії · Вигляд і ефекти · Сповіщення й автоматизація (Telegram + сокет + автооцінювання, згруповані тумблери) · M1-посилання · Плагіни (сторінка плагіна з вкладками Огляд/Налаштування/Логи/UI) · Для розробника. |

**Онбординг:** CTA «Почати» → реєстрація → «Підключи MyStat» (вбудований крок з поясненням про паролі) → екран синхронізації з прогресом і скелетоном дашборду. `/accounts` — лише керування. Додати «Забув пароль?» (потребує бекенду) і перейменувати `/reset` на `/clear-cache`.

**Лендінг:** один сильний hero-момент ≤2 с (або інтро лише при першому візиті), прибрати canvas-уламки/літери за курсором; скріни — AVIF/WebP; без `data-sveltekit-reload`.
