# Плагіни M1 ID

Платформа плагінів для M1 ID: «сплячі лямбда»-плагіни на Python + веб-вкладки (HTML/CSS/JS у sandbox).

## Як встановити плагін
1. Відкрий вкладку **Плагіни** в застосунку.
2. Натисни **Завантажити zip** або **файли** і обери `.zip` з маніфестом (`manifest.json`) та кодом (`plugin.py`), або ж окремі файли.
3. Прийми дозволи → **Встановити** → увімкни перемикачем.

Приклади в цьому репозиторії:
- `hw-watch/` — нагадування про дедлайни ДЗ + віджет-лічильник
- `streak-note/` — TG-команда `/notes` (нотатки в storage) + вкладка-список

Запакувати приклад у zip (PowerShell):
```powershell
Compress-Archive -Path plugins/streak-note/* -DestinationPath streak-note.zip
```

## Модель безпеки
- Плагін — **одноразова лямбда**: прокидається лише на подію (TG-команда, poller-подія, відкриття вкладки), виконується ≤2с у ізольованому subprocess і вбивається.
- **AST-аналізатор** перед кожним запуском: білий список модулів (json, math, random, re, datetime, textwrap, statistics, string, itertools, collections, functools); заборона `eval/exec/compile/__import__/open`, dunder-атрибутів/рядків, `__builtins__`.
- **Сліпий API**: ПІБ/пошта/телефон/логіни підмінюються псевдонімами `#T1, #T2…` до передачі плагіну і відновлюються лише на виході. Імена в лідерборді — публічні.
- Кастомні вкладки рендеряться в `<iframe sandbox="allow-scripts">` (без same-origin), дані — через `postMessage`.
- **TG-ліміти**: 60 повідомлень/год на юзера (усі плагіни разом), 30/год на плагін; при вичерпанні — `RateLimitExceeded`.
- Плагіни мають окрему БД `plugins.db` і власне storage (JSON, ліміт з маніфесту).

## Розробка плагіна
Єдина спека для розробника та ШІ-асистента: **[DEV.md](DEV.md)** — модель виконання («спляча лямбда»), маніфест, дозволи і payload-секції, хуки з прикладами, postMessage-протокол, сліпий API, AST-заборони, ліміти TG, чекліст.

Коротко: `plugin.py` з хуками `on_install / on_uninstall / on_event / on_ui / on_command_<cmd> / on_button_<id>`, кожен отримує `ctx` (event, payload, params, settings, storage, args_text) і повертає `dict` з `data / text / notify / storage`.

Вкладка Плагіни → **Логи** у картці плагіна: статус, тригер, тривалість, помилки кожного запуску.
