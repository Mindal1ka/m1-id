# DEV.md — нотатки розробки M1 ID

## ⚠️ Пісочниця плагінів — БАЗОВА (H4, BUGS.md)

Плагіни виконуються через `exec()` у worker-процесі (`plugins/worker_boot.py`)
з урізаними builtins + AST-фільтром на аплоаді. Це **не межа безпеки Python**:

- обхід через `getattr` на прихованих об'єктах в args/винятках, format-трюки
  тощо **не гарантовано** блокується;
- на POSIX додано `setrlimit` (RAM 512МБ / CPU 2с), на Windows лишається
  лише kill за таймаутом 2с — ліміту пам'яті немає;
- запуск іде з `-I` (ізольований режим), окремий процес на кожен хук.

**Для ненадійних авторів плагінів потрібна реальна ізоляція**: окремий
контейнер/OS-користувач, gVisor або подібне. Не розгортати маркетплейс
сторонніх плагінів без цього.
